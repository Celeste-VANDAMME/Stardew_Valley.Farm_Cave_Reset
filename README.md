# Stardew_Valley.Farm_Cave_Reset
A lightweight and really simple code that allows you to choose again which cave you want in Stardew Valley (for in-game version 1.16)

## Features
Here are the features so far:
- Automatically find the path for saves in %AppData%
- Let you choose which one you want to reset (in terminal for now)
- Create a backup (.zip) before changing anything (using ZipFile)
- Reset your farm cave farm (based mostly on 1.0 code)
